
# VIZ Patch — Avee Player VIZ Image Replacer

**VIZ Patch** is a free online tool for replacing embedded image resources in Avee Player `.viz` visualizer templates.

Created by **Thilii Music**, VIZ Patch works directly in your web browser and lets you modify image resources without manually editing ZIP archives.

🌐 **Use VIZ Patch:** https://thilina200389.github.io/viz-patch/

## Features

- Import Avee Player `.viz` templates
- Find and replace embedded image resources
- Export modified templates as `.viz` files
- Works in modern desktop and mobile browsers
- Processes VIZ files locally in your browser
- No account or software installation required

## How to Replace Images in an Avee Player VIZ File

1. Open the VIZ Patch website.
2. Import your `.viz` template.
3. Select the embedded image resource you want to change.
4. Choose a replacement image.
5. Export the modified `.viz` file.
6. Import the exported template into Avee Player.

## Frequently Asked Questions

### Can I replace images in an Avee Player VIZ template online?

Yes. VIZ Patch allows you to import a `.viz` template, replace embedded image resources, and export the modified file using a web browser.

### Can VIZ Patch help when Avee Player crashes while changing images?

VIZ Patch provides an alternative way to replace embedded images outside Avee Player. It may help with some image-changing issues, but it cannot guarantee a fix for every crash or template.

### Does VIZ Patch work on Android?

Yes. VIZ Patch can be used in a compatible Android browser. You can export the modified `.viz` file and import it into Avee Player.

### Are my VIZ files uploaded to a server?

No. VIZ Patch processes files locally in your browser.

### Is VIZ Patch an official Avee Player tool?

No. VIZ Patch is an independent tool created by Thilii Music and is not affiliated with Avee Player.

## Limitations

- Some VIZ templates may contain unsupported or unusual image resources.
- Replacing an image does not guarantee that a template will work correctly in Avee Player.
- Keep a backup of your original VIZ template before editing.
